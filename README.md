# Reproducing the figures and results of *From Signals to Measurands*

This repository contains the code, fixed-seed synthetic observations, figures,
and machine-readable reference results for:

> **From Signals to Measurands: A Measurement-Science Roadmap for Reproducible Analytical Biochemistry**  
> Santiago Schnell, manuscript prepared for *ACS Measurement Science Au* (2026).

No external data are required. The synthetic observations used in the worked
Michaelis-Menten example are generated by the code and are also deposited as
CSV files, so the analysis can be audited without regenerating them.

The workflow has two parts:

1. `python run_all.py` regenerates the table-of-contents graphic, Figures 1-3,
   and the numerical values in Supporting Information Tables S1-S3 and S5. It
   uses random seed `20240530`.
2. `python code/validate_schedules.py` separately regenerates the
   sampling-schedule comparison in Supporting Information Table S4. It uses
   random seed `20240531`.

Together, these commands reproduce the numerical content of Supporting
Information Tables S1-S5.

## Quick start

Python 3.11 or newer is required.

```bash
python -m venv .venv
```

Activate the environment:

**Windows**

```bash
.venv\Scripts\activate
```

**macOS or Linux**

```bash
source .venv/bin/activate
```

Install the pinned dependencies and run the principal workflow:

```bash
python -m pip install -r requirements.txt
python run_all.py
python -m pytest tests
```

On systems where `python` invokes Python 2 or is unavailable, use `python3`.
Conda users can instead run:

```bash
conda env create -f environment.yml
conda activate signals-to-measurands
python run_all.py
python -m pytest tests
```

The principal workflow takes tens of seconds to a few minutes depending on the
computer. Figure 1 performs 400 simulation-and-recovery fits for each design.

## Reproducing Supporting Information Table S4

The schedule study performs approximately 18,000 conditional profile fits and
is deliberately kept separate from the principal workflow:

```bash
python code/validate_schedules.py
```

Progress is streamed to the terminal. The script writes its machine-readable
result to `figures/schedule_validation.json`. Re-run the tests afterward to
compare that result with `tests/reference_schedules.json`:

```bash
python -m pytest tests
```

nominal 95% threshold.

## Measurement and fitting conventions

### Initial substrate concentration

`[S]_0` is a separately calibrated input obtained from an independent initial
absorbance measurement on the same Beer-Lambert scale as the progress-curve
observations:

```text
[S]_0 = A0_cal / (epsilon * path length)
```

It is not estimated from the first noisy progress-curve datum. In the
illustrative uncertainty budget, repeatability uncertainty in `A0_cal` and
uncertainty in the 1 cm path length are neglected. Because the observations
and `[S]_0` share the same calibration scale, perturbing the absorption
coefficient rescales `V` and `K_M` together and leaves `V/K_M` invariant.

### Numerical parameterization

`V` and `K_M` have different units and poorly matched numerical scales in the
chosen parameterization. The fit therefore uses `log(V)` and `log(K_M)` from
several starting points. The reported reference residual is the lowest value
found by that bounded multistart procedure; the repository does not claim an
analytical proof of global optimality.

### Nonpositive transformed observations

Three Design I concentration estimates are nonpositive because additive
absorbance noise exceeds the residual signal near depletion. They are retained
at their observed values in all fits. Figure 1 displays them as downward
triangles at a declared plotting floor because a logarithmic ordinate cannot
show nonpositive values.

## Which script produces which result

| Script | Output |
| --- | --- |
| `generate_toc.py` | table-of-contents graphic |
| `generate_figure1.py` | Figure 1; SI Tables S1-S3 and S5; deposited observations; `current_results.json` |
| `generate_figure2.py` | Figure 2 |
| `generate_figure3.py` | Figure 3 |
| `validate_schedules.py` | SI Table S4 and `schedule_validation.json` |

The figure scripts can also be run individually. For example:

```bash
cd figures
python ../code/generate_figure1.py
```

`generate_figure1.py` is safe to import: all analysis and file writing occur
inside its `main()` function. The schedule validator imports the shared model
and fitting functions without regenerating Figure 1 or creating unrelated
files.

## Reproducibility and numerical tolerance

The random seeds fix the synthetic observations. Fitted values can still vary
slightly with the SciPy version, BLAS/LAPACK implementation, operating system,
and floating-point behavior. The test suite therefore compares the scientific
results with committed reference values using numerical tolerances rather than
requiring byte-identical optimizer output.

The deposited figures were produced with:

- Python 3.11 or newer;
- NumPy 2.4.4;
- SciPy 1.17.1;
- Matplotlib 3.10.8;
- pytest 9.0.2.

The scripts use Matplotlib's bundled DejaVu Sans fonts; no proprietary fonts are
required.

## Methodological references

The progress-curve model uses the Schnell-Mendoza closed-form solution of the
integrated Michaelis-Menten equation:

- Schnell, S.; Mendoza, C. *J. Theor. Biol.* **1997**, *187*, 207-212.
  DOI: 10.1006/jtbi.1997.0425.
- Goudar, C. T.; Sonnad, J. R.; Duggleby, R. G. *Biochim. Biophys. Acta*
  **1999**, *1429*, 377-383. DOI: 10.1016/S0167-4838(98)00247-7.

The Perspective also identifies higher-level open-source tools, including
PyEnzyme for EnzymeML records and LMFIT for nonlinear estimation and confidence
exploration. Those packages are not required for this reference implementation.
